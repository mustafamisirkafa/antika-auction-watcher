## ?? Preference Logic (Complete)

### Backend Decision (BidPolicy)
```python
# 1. Check user preferences
if seller_id and source:
    preference_check = await self._check_user_seller_preferences(...)
    if not preference_check["allowed"]:
        return {"ok": False, "blocked_by": "user_preference"}

# 2. Check blocklist (highest priority)
if seller in blocklist:
    return DENIED

# 3. Check allowlist
if allowlist.empty:
    return ALLOWED  # Default open
elif seller in allowlist:
    return ALLOWED
else:
    return DENIED  # Restricted mode
```

### Frontend Update (Optimistic)
```typescript
// 1. Update Zustand immediately
addToBlocklist(seller)

// 2. Call API
await updateUserPrefs({action: 'add_block', ...})

// 3. On success: Invalidate cache + refetch
// 4. On error: Rollback + show toast
```
